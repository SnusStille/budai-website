# Workspace and history reliability pass

The existing Workspace now supports explicit, device-only saving of one draft per guest/account namespace, a Markdown preview and returning to an open draft after closing the panel. It does not sync the saved draft to Supabase, share it between devices or store it automatically. Temporary chats cannot save a device draft. Users can reopen or delete the saved draft; replacing a different saved draft requires confirmation. Unsaved edits are protected before starting or opening another chat. Closing the panel keeps the draft in memory for this page session. The existing Markdown download and clipboard remain available.

On mobile, Workspace uses a portal above the site's other controls, moves focus to its close button, contains tab navigation and returns focus when closed. Actions use the edited draft and do not attach a pending image. The 3,200-character action limit remains in place; the document itself can be saved locally up to 100,000 characters. AI actions still use the current conversation as context and consume a normal message.

Cloud history previously generated prefixed short message IDs while the database assigned different UUIDs; repeated snapshots could reinsert messages. New messages use stable UUIDs, inserts carry a client ID, reads match either database or client IDs, and same-tab writes to a conversation are serialized. Failed reads or inserts do not fall back to new IDs, and the UI reports sync failure. This prevents the identified same-tab repeated-snapshot duplication for new messages; it does not retroactively remove existing duplicates or guarantee conflict-free concurrent writes from separate devices. No schema change is required.

The tests use local browser transport doubles and an in-memory Supabase-shaped test double. They do not certify a live database or provider. Local drafts are accessible to anyone using the same browser profile and may be lost if site data is cleared; do not save sensitive information on shared devices. Sign-in changes the active account namespace, not the saved data's physical storage. No new service or dependency was added.
